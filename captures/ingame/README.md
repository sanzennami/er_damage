# 客户端截图投放目录

把《永恒轮回》客户端里截的技能界面图片放在这个目录，Claude 从图里读数并写进
`src/data/inGameSkillCapture.json`。图片本身被 `.gitignore` 排除，不会进仓库。

## 截图怎么截

1. 客户端设成**窗口化**（全屏独占模式下系统截图容易黑屏）。
2. 藏品 → 选实验体 → 逐个技能，把**技能说明浮窗**连同数字一起截进去。
3. **只截 LEVEL 1 一张，剩下的用文字说**（比逐级截图快得多）。格式例：

   > 希瑟拉 Q：LV2 CD7 50 115；LV3 CD6 60 150；LV4 CD5 70 185；LV5 CD4 80 220

   数字顺序照着截图里出现的顺序念（这里是「路径伤害 落点伤害」），冷却写 `CD<秒>`。
   系数（+技能增幅30% 之类）一般各级相同，只在变化时说一声。

   等差数列直接说规律更省事，例如「消耗 50，之后每级 +10，LV5=90」「CD 17,16,...,13」。
4. `Win+Shift+S` 框选 → 粘贴保存，或者用 `PrtSc` 全屏截图都行。

等级没凑齐的条目会先进 `drafts`，App 不读，**不会**拿半截数据污染现有数值 —— 所以随时可以只交一部分。

## 命名

```
<实验体>-<槽位>[-lv<等级>][-备注].png
```

例：`杰琪-Q-lv1.png`、`杰琪-Q-lv5.png`、`Jackie-P-lv3-流血.png`

名字只是给人看的索引，读数以图片内容为准；实在懒得改名，直接丢原始文件名也能处理，
只要告诉我大致是谁的技能。

## 一张图要看清什么

- 实验体名 + 技能槽位（P/Q/W/E/R）
- 技能名
- **说明里所有数字**：基础伤害、系数（+攻击力 45% / +技能增幅 40%）、冷却、消耗
- 界面上标的**当前技能等级**（很关键，决定这组数字落到 lv 几）
- 一个技能说明里有**几段伤害**（例如希瑟拉 Q 是「路径」+「落点范围」两段），每段单独入库
- 右侧「属性」面板如果一起截进来了更好：**统计**栏（Lv1/Lv20 的体力上限、攻击力、防御力）和
  **武器熟练度**栏（Lv1/Lv20 的攻速、技能增幅…）会一并录入。这两份数据仓库里已经有，
  录入时会先对账，对得上就只留证据，对不上才覆盖并报冲突 —— 所以顺手截上等于免费做了一次校验。
  「各级别补正值」（钴协议模式 / 孤狼）不用管。
- 熟练度是**按武器类别**的，同一个实验体换武器数值不同；截图时留意左上选中的是哪个武器类别。

数字模糊、被鼠标挡住、或有截断，就再截一张 —— 读不准的条目我会标
`"confidence": "needs-recheck"` 而不是猜。
