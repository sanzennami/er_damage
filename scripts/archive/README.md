# 已归档脚本

这两个脚本是 **11.3 ~ 12.0 的一次性历史回填**，设计上是「增量式」：以官方公告的「改前值」作校验基准，
因此不可重复执行，重跑前必须 `git checkout -- src/data` 还原数据。

这个设计不适合跟随版本更新的工具，已被 `scripts/apply-patch-log.mjs` 取代：

| | 归档脚本 | 现行脚本 |
| --- | --- | --- |
| 记录方式 | 增量（A → B） | 目标态（该补丁之后应该是什么值） |
| 校验基准 | 改前值必须匹配 | 当前值是否已等于目标值 |
| 重跑 | 必须先还原数据 | 随时可跑，已达标自动跳过 |
| 加新版本 | 改脚本代码 | 往 `src/data/patchLog.json` 追加一段 |

它们产出的历史记录已经转成目标态形式，保存在 `src/data/patchLog.json`；
`docs/official-patch-updates/` 里的报告仍是当时的应用留档。

保留这两个文件只为追溯，**不要再运行**。
